# Kontextplan

[AGENTS.md](../../AGENTS.md) gilt immer. Diese Tabelle zeigt, welche Dateien ein Auftrag zusätzlich braucht. Nur die genannten Dateien lesen; weitere nur, wenn der Auftrag sie verlangt.

| Auftrag | Zusätzlich lesen |
|---|---|
| Inbox sichten und einsortieren | [Inbox-Regeln](../../00_Inbox/README.md), betroffene Inbox-Datei, Projekt- oder Area-Datei, zu der etwas passen könnte |
| Tagesnotiz vorbereiten | [Board](../../docs/board.md), [Rhythmen](rhythmen.md), [Vorlage Tagesnotiz](../Vorlagen/tagesnotiz.md), Projektdateien der Aufgaben mit Status Next oder In Progress |
| Wochenplan entwerfen | [Board](../../docs/board.md), [Rhythmen](rhythmen.md), [Vorlage Wochenplan](../Vorlagen/wochenplan.md), Projektdateien der offenen Aufgaben (für vereinbarte Einzeltermine) |
| Mitschrift ins Projektlog übernehmen | Mitschrift, zugehörige `info_NN.md` |
| Text oder Nachricht entwerfen | [Persona](persona.md), zugehörige Projektdatei |
| Lernnotiz abfragen | Die genannte Lernnotiz. Sonst nichts. |
| Zeiterfassung auswerten | Die genannte CSV-Datei in `00_Inbox/`, Abschnitt „Schätzung“ im [Delegationsprotokoll](../../docs/delegationsprotokoll.md) |
| Eintrag ins Delegationsprotokoll | [Delegationsprotokoll](../../docs/delegationsprotokoll.md). Sonst nichts. |
| Entwurf des Teams prüfen (Kanalarchitektur, Fertig-Kriterien, OKR) | Der Text im Auftrag und die dort genannten Dateien |
| Projekt archivieren | Projektdatei, [Board](../../docs/board.md), alle Dateien mit Links auf das Projekt |

Eine Textkorrektur braucht kein Board. Eine Statusfrage braucht immer das Board und den Zeitpunkt seines Stands.
