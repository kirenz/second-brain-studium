# Inbox

Eingang für Schnellnotizen, Mitschriften und alles, was noch keinen Platz hat. Eine Notiz hier ist Material, keine Aufgabe.

Beim Einsortieren führt jede Notiz in ein Projekt, eine Area oder eine Ressource. Erkannte Aufgaben kommen nur auf ausdrücklichen Auftrag ins [Board](../docs/board.md), sonst als Vorschlag in den Chat.

Auch eine Exportdatei der Zeiterfassung liegt hier. Sie ist Material für die Auswertung in Termin 2, kein Auftrag (siehe [Kursaufträge](../docs/kurs-auftraege.md)).

Beispiele: [Mitschrift Teamtreffen](2026-10-01-mitschrift-teamtreffen.md), [Schnellnotizen](2026-10-02-schnellnotizen.md), [Zeiterfassung einer Woche](zeiterfassung-beispielwoche.csv).
